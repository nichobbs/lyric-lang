# Book: a WebAssembly chapter

The wasm32 material that had accumulated in `book/chapters/01-getting-started.md` moves
into a new Chapter 32 (`book/chapters/32-webassembly.md`): the toolchain, a plain WASI
program, the module and component shapes, host imports, the `[wasm]` and `[npm]` tables,
the NPM shim workflow, the diagnostics and what is not supported yet. Getting Started
keeps a pointer; Chapter 13 gains a section on the JavaScript boundary.

Status lines that still described the target as only specced are corrected in
`docs/35`, `docs/36`, `docs/06` and `CLAUDE.md`.
