# The I0001 gate as warning W0036 (#8613)

D341.

- The checker records non-callee expressions typed `TyError` with no diagnostic
  and reports them as W0036 under `LYRIC_TYERR_GATE=1` (the stage 2 bootstrap emit sets
  it). Callee positions are exempt by a named predicate; a file with an error
  reports none. Unit tests in `typechecker_self_test.l`.
- Local census with the gate on over the compiler and stdlib closure
  (`LYRIC_TYERR_GATE=1 ./scripts/bootstrap.sh --stage 2`, then
  `grep W0036 .bootstrap/stage2-emit.log`): 1859 warnings. It counts every
  expression that reads a silent-`TyError` value, so it is above D338's 1,161
  root sites. the stage 2 bootstrap prints the count and the sites.
