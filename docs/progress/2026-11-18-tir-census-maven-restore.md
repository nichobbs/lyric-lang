# docs/70 phase 3a: the self-tests census restores lyric-web's and lyric-ws's Maven dependencies

The wide census reported 24 "an extern call the host metadata cannot resolve" and 2 "no host overload fits" (26 bodies of `Web.Kernel.Runtime` and `Ws.Kernel.Jvm`). They are Undertow calls, and the census built them without the `[maven]` jars a real `--target jvm` build restores, so the host metadata had nothing to resolve them against. The self-tests area now runs `lyric restore` for `lyric-web` and `lyric-ws` first, with the resolver `make maven-resolver` builds, and says so (with a NOTICE) where the resolver or the network is missing. With the restore, `jvm_auto_ffi_bridge_self_test.l` builds 18 of the 24 `Web.Kernel.Runtime` bodies and none is counted as an unresolvable host call; what remains there is a fixture's deliberately unresolvable `JUnresolvable` type and bodies of other kinds (`serve`, `serveTls`: a call the checker did not resolve).
