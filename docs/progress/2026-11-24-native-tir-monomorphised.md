# 2026-11-24: native TIR lowers the monomorphised bundle (D533)

`lyric build --target native --via-tir` now monomorphises the bundle's TIR (`Lyric.Tir.Mono.monoBundle`, D500) before lowering: the user package and the bundled standard-library packages are checked with one shared DefPath interner, each unit receives its own monomorphised TIR plus the shared instances package, instance records and unions take the layouts the code generator's own instantiation gives them, and an instance function is lowered from TIR under its AST copy's IR name. `fallback.l` (generic record, union and function) lowers 5 of 5 functions from TIR and runs clean under AddressSanitizer. Project builds monomorphise too, and a generic function of another package is instantiated on demand when a TIR call names it (see D533).

On the native self-test census (`scripts/ci/native-via-tir-census.sh`, 20 suites) the functions lowered from TIR went from 1166 to 1398 of 1744; the 81 contract fallbacks (phase 3c elaboration) are the largest remaining group, then module-level `val`/`const` reads (`XGlobal`, 43) and `nativeAddrOf` (27). Range-free distinct types and `List`/`Map`/tuple instance arguments lower too.
