# `Unit` is an ordinary type with one value, on dotnet, the JVM and native (#8236, #8266)

A `Unit`-typed parameter, field, closure capture or type argument used to be lowered as "no value", so anything that had to store one failed differently on each target: `InvalidProgramException` / `TypeLoadException` on dotnet, J008 (stackmap underflow) or "no matching method `ArrayList.add(V)`" on the JVM, and `void %u` parameters that clang rejects on native. The repo owner decided (2026-10-23, D271) that `Unit` is an ordinary type with exactly one value, materialised wherever a parameter, field, local, return slot or type argument needs storage, on every target. `func f(): Unit` keeps its void calling convention where nothing reads the result.

- **dotnet.** `msil/lowering.l` encodes a `Unit` parameter or field as `object` (`unitStorageSlotType`); only a return slot stays `void`. `msil/codegen.l` applies the same rule where it registers a parameter's, field's, lambda parameter's, closure capture's or generic type argument's logical type, follows a void call that is passed on or stored with `ldnull` (`lowerValueExprMsil`), keeps an annotated `Unit` binding's initialiser storage, and drops a `Unit` tail with `pop` before the void `ret`.
- **JVM.** `Jvm.Lowering.unitStorageType` maps `JVoid` to `Object` in method descriptors, record/union/protected fields, lambda parameters and closure captures; `lowerValueExpr` pushes `aconst_null` for a void result that a call or constructor argument consumes. A virtual `Unit` local takes no JVM slot (it used to reserve one that the StackMapTable left as a hole), and `return u` / `= u` in a `Unit` function drops the value.
- **native.** `Lyric.LlvmIr` prints an `NVoid` parameter as `i8` and an `NVoid` call argument as `i8 undef`; only a return type prints `void`. A closure capture field is `i8`, a `Unit` closure parameter or capture is a virtual binding, and a `List`/`Map`/`Task` slot of `Unit` is the zero word.
- **Stringification.** The one `Unit` value renders as `()` on all three targets (`toString`, interpolation, `+`, `println`/`print`), where dotnet used to render a void call as an empty string, the JVM rejected it with J008 and native with N0007; a null in an erased `object` slot is the unit value and renders as `()` instead of faulting.
- **Tests.** `lyric-compiler/lyric/unit_value_self_test.l` (24 cases) runs on all three targets: a `Unit` parameter on a free function, a record method, a protected entry and member and an interface method; `T = Unit` for a generic function, a generic function returning a lambda over `T`, a generic higher-order function, a generic record field and a generic record method; `Result[Unit, E]` with `?`, `Option[Unit]`, `List[Unit]`, `Map[String, Unit]`; lambdas and `(Unit) -> Unit` function values; annotated bindings, forwarding and closure captures. Registered in the dotnet, JVM and native CI batches and in the ilverify list.
- **Docs.** D271 records the decision and the representation per target; docs/01 §2.1, docs/09, docs/18 §4.5 and `native/plan/03-type-mapping.md` describe it.

Closes #8236 and #8266.
