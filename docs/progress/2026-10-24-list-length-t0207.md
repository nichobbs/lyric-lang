# `.length` on a `List` is T0207 (#7218)

`xs.length` on the stdlib `List` type-checked silently, compiled on `--target dotnet` (lowered to `Count`) and failed
on `--target jvm` with `J009`. The front end now rejects it: **T0207** names `.count` (D223). `.length` is unchanged on
`String`, `slice[T]` and arrays, and a package's own `record List[T]` is untouched.

- Check: `maybeUnknownMemberDiag` in `type_checker/typechecker_exprs.l`, reached from both the member and call paths.
- Migration: every `.length` on a `List` found by checking all packages, tests and examples with the new diagnostic was
  changed to `.count`. Compiler sources were migrated in the same change so the seed compiler and the new check both
  accept them.
- Tests: `typechecker_self_test.l` (`.length on a List is T0207 and names .count`, the call form, the String/slice/List
  clean case, and a user-defined `List` record), already registered in CI.
- Docs: `docs/01-language-reference.md`, `book/chapters/03-data-structures.md`,
  `book/chapters/appendix-b-quick-reference.md`.
