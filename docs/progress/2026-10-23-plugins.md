# Plugins: language surface, runtime, wasm mode, CLI and generators (D207)

- **Language surface** (D207 Decisions 1-2): `@capability`, `@plugin_point`, `@protocol_point`,
  `@plugin_handle`, `@plugin`, `@plugin_contributions` and `@plugin_request`, expanded by
  `Lyric.PluginExpand` (`lyric-compiler/lyric/plugin_expand/`) after `Lyric.WireExpand` on every
  backend. It generates the boundary codecs (D207 Decision 4), `<C>Client` / `<C>Server` /
  `<c>Provider` per capability, `<P>Remote` / `<p>Remotes` / `pluginDispatch<P>` /
  `<p>Contributions` / `<p>ContributionIssues` per point, and a plugin's server and `main`.
  `requires:` clauses naming `grant` move to the host side. Diagnostics K0000-K0012.
- **Runtime**: `Std.Plugin` (`lyric-stdlib/std/plugin.l`, kernels `Std.PluginHost` and
  `Std.PanicGuardHost`): manifests, discovery, grant policies, process supervision, call
  timeouts, cancellation, revocation, and the plugin-side `runPlugin`. Hosts run on dotnet, the JVM and
  native; payloads are dotnet, JVM, native or wasm32-wasi modules under `wasmtime run` (no
  directories, environment or network, memory capped). Load codes K0101-K0103.
- **CLI**: `lyric plugin pack`, `check` and `sdk` (`Lyric.PluginManifest`, `Lyric.PluginSdk`),
  generating C#, Java and TypeScript SDKs plus JSON Schema.
- **Generators** are the first plugin point: `Lyric.GeneratorSdk` 2.0.0 declares
  `SourceGenerator` (version 3.0) and the `ProjectRead` capability; the generated codecs replace
  the hand-written JSON driver. The compiler hosts each generator as a dotnet payload and serves
  `ProjectRead` itself. `examples/generators/describe`, `Forms.Derive` and `Ui.Routes` are
  `@plugin` records; X0003 now asks for one.
- **Fixes found on the way**: generated helpers no longer call `lastIndexOf`, which a package
  importing `Std.String` resolved to the `Option`-returning stdlib function; a consumer of a
  built plugin API package rechecks its contract with the `Std.Plugin` / `Std.JsonRpc` types
  accepted; the compiler's generator request names a field default `defaultSource`.
- **Tests**:
  - Self-tests: `plugin_expand_self_test.l` (43), `plugin_codec_self_test.l` (6),
    `plugin_manifest_self_test.l` (13), `plugin_sdk_self_test.l` (11),
    `restored_packages_self_test.l` (29), `generator_self_test.l` (28).
  - `lyric-stdlib/tests/plugin_manifest_tests.l` (27).
  - `scripts/ci/plugin-e2e.sh`: the runtime against a real plugin process (10).
  - `scripts/ci/plugin-generated-e2e.sh`: an annotated plugin against generated host code (8), on
    every dotnet/JVM host and plugin pair.
  - `scripts/ci/plugin-sdk-e2e.sh`: C#, Java and TypeScript plugins.
  - `scripts/ci/source-generator-e2e.sh`: dotnet and JVM.
- **CI**: `scripts/ci/plugin-suites.sh` (managed targets) replaces the source-generator step;
  the wasm plugin runs in the wasm32 job and native hosts in the native job; the plugin
  self-tests join `scripts/ci/compiler-self-tests-batch.sh`.
- **Docs**: D207 (with implementation notes), docs/69, docs/40, docs/01 §15, book chapter 33 and
  chapter 30, appendix B, the generator SDK README and protocol.
- **Deferred** (D207): trusted in-process mode, signing (Q-PLG-006), the registry (Q-PLG-007),
  K0104 (interface hash).
