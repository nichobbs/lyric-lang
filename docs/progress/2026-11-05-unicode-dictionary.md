# Dictionary word segmentation for Thai, Lao, Khmer and Myanmar (#8497)

`lyric-unicode-dict` is a new, opt-in library on top of `lyric-unicode` (D414). `Unicode.Dictionary` ports
ICU 74.2's dictionary break engines for Thai, Lao, Khmer and Burmese. `Unicode.Dictionary.Data` holds ICU's
own word lists, generated by `tools/generate` from the dictionaries pinned in `dict/`. `lineBreaksIn` and
`wordBoundariesIn` add the dictionary's breaks inside runs of these scripts to `lyric-unicode`'s rule-based
results.

The conformance suite is ICU itself. `tools/reference`, a Lyric native program calling ICU 74.2, recorded
the line and word breaks of 4000 generated lines in `tests/conformance/DictionaryBreakTest.txt`. Every line
agrees on dotnet, the JVM and native, and the suite runs in CI with the `unicode` matrix entry and the
native lyric-ui job. Using it from `lyric-text` and the native lyric-ui host is #8832.
