# Native: `examples/ui-customers` lowers end to end; async interface methods dispatch (#8155, #7990)

- `examples/ui-customers` now compiles to LLVM IR with `--target native`. The build stops only at the external `-lwebview` link; the libwebview build and a desktop smoke are the rest of #8155.
- Async interface methods dispatch through the vtable on native: the slot returns the task handle, `NIfaceInfo.methodAsyncElem` records the declared result, and the call site unwraps it like any async call (a `wantTask` call keeps the task). Async `impl` methods are collected like sync ones. Protected-type async methods are still excluded.
- Bare type, function and union-case names now resolve to what the code means when several packages declare the same name: a package's own declaration first, then a package it imports, then the bundle-first fallback. Covered: types (`lookupHeapType`), union cases (`curPkgQualifiedGet`, incl. `Type.Case`), a callee's declared parameter and return types (resolved in the callee's package), record, union and protected field types (resolved in the declaring package), and a bare call that an imported generic should win over a non-imported package's same-named function.
- Type inference gaps closed for native: a cross-package function value passed to a generic record constructor takes its closure type from the callee's signature; the checker's inferred type arguments are written onto a generic call that has a lambda argument (`spellLambdaGenericCallTypeArgs`), and explicit type arguments now apply to a package-qualified callee; an unannotated lambda local inside a generic function is annotated with its type, type variables spelled by name (`SymbolTable.spellTypeVarsInLocalFuncs`, native checks only); a bare `None` argument takes its type from an earlier argument of the generic call.
- Tests: 9 cases in `llvm_project_self_test.l` and 2 in `llvm_self_test_async.l`, each built so a wrong resolution misreads data or fails to type-check.
- Open: #8155 item 2 (libwebview link, desktop smoke), #7990, #8154 (condition variables, `when:` barriers).
