# lyric-gpu: compute and offscreen render (docs/67 G5, #7944, D194)

- `lyric-gpu/`: bindgen-generated `Gpu.Kernel.Wgpu` over wgpu-native v29.0.1.1 (pinned wheels via
  `[native.libs]` prebuilt) and the safe `Gpu` package: `withDevice` (scoped device), buffers, WGSL compute pipelines,
  bind groups, dispatch, `readInts`; offscreen RGBA8 targets, render pipelines, `render`,
  `readPixels`.
- Type checker: `NativePtr[Byte]` converts to any `NativePtr[T]`; `NativePtr[Record]` converts to
  `NativePtr[Byte]` (typechecker_self_test).
- bindgen: constants keep sign and are only integer literals; allow-list userdata indices
  corrected for webgpu's callbacks.
- Examples and CI: `examples/compute`, `examples/triangle` (golden image), run on lavapipe by
  `scripts/ci/gpu-examples-e2e.sh` in the native-backend job; bindings checked with `--check`.
- Remaining G5: textures and samplers (textured quad), surface present (after G4), see #8404.
- Docs: D194, language reference §11.6, book chapter 13, docs/67.
