# Native: generic impls, receiver-aware reachability, bundled `?` records (#8300, #8413, #7212, #8448)

Part of the native-backend group. Per issue:

- **#8300 (`impl[T]` for a generic target).** `Lyric.LlvmCodegen` skipped every
  `impl[T] I for R[T]`, so `p.first()` on a `Pair[Int]` was N0007. The impl's
  methods are now registered as generic functions of the record
  (`registerGenericImplMethods`, under `<Pkg>.<R>.<m>/<n>` and the
  interface-qualified `<Pkg>.<R>.<I>.<m>/<n>`), so a member call specialises
  them like a record's own methods, and the first upcast of an instance to the
  interface emits that instantiation's vtable (`genericImplVtable`; a by-value
  record gets the box thunks as for a non-generic impl). Generic-function
  instantiation moved into `ensureFnInst`. Tests: `generic_impl_self_test.l`
  (dotnet, JVM, native); the impl case of `generic_closure_self_test.l` now
  runs on native.
- **#8413 (reachability by bare method name).** The reachability walk now keeps
  the checker's receiver class (`memberRecvClasses`) on a UFCS call key and
  drops candidates the class cannot reach: a dot-named function of another
  nominal type, a free function whose first parameter is another nominal or
  built-in type, and a pruned dependency group of another type. Keys with no
  recorded class behave as before. Only the user and project packages carry
  the checker's classes; a call inside a bundled stdlib body is still matched
  by name. Test: `scripts/ci/native-reachability-e2e.sh` (IR check with a
  `String`-receiver control), wired into the native CI job.
- **#7212 (bundled `?`-hoist records).** `llvm_bridge.l` now calls
  `lowerPropagateFileWithExtraRecords` for bundled stdlib packages with the
  records of every package visible to that package. No bundled package
  triggers the hazard today, so the full native suite is the regression check;
  the hoist's own behaviour is covered by `propagate_hoist_entry_polarity_self_test.l`.
- **#8448.** Already fixed on main: `generic_member_calls_std_self_test.l` passes
  on native. It now runs in the native lists.

Not done: #7891 (captured-`var` boxing, `println` of non-scalars, `String + Int`,
`UInt`/`ULong`) and the rest of #8167 (`Set`, tuple keys, extending
`structural_equality_self_test.l` on native); see the PR description.
