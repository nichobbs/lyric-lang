# docs/70 phase 3a: the CI census clears library outputs before the typed-IR census

`library-tyerr-census.sh` builds every library for dotnet, then the JVM, and a JVM build writes its jar under the same `.dll` name in the library's `bin/`. The typed-IR census that runs next in the same job builds the libraries for dotnet again and restores their dependencies from those directories, so nine libraries (`lyric-ui`, `lyric-ui/native`, `lyric-access`, `lyric-conformance`, `lyric-db`, `lyric-grpc`, `lyric-jobs`, `lyric-otel`, `lyric-testing`) were listed unchecked in CI with "restored DLL has no Lyric.Contract resource", and never locally. The script now removes untracked library `bin/` directories before the typed-IR census. The reasons were read from the CI log of #9212, which prints why an unchecked build failed; whether this clears all nine is confirmed by the next CI census.
