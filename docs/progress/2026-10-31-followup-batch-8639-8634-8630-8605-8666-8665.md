# Follow-up batch: #8639, #8634, #8630, #8605, #8666, #8665

- **#8639 (JVM).** A restored package's synthesised source keeps no imports, so
  a bare type in a signature (`Uuid`, re-exported from `Std.Uuid`'s kernel)
  found no extern seed and its descriptor named the producer package as the
  owner (`NoSuchMethodError`). The JVM bridge now gives each restored artifact
  the imports its contract records before seeding its signatures.
- **#8634 (JVM).** `P.f()` inside `package P` resolved no signature for a
  package-private `f` (only the package-scoped key registers it), losing the
  return type (J007). `resolveGeneralFuncSig` tries the own-package scoped key
  when the qualifier is the current package.
- **#8630 (MSIL).** A lambda in a branch of a returned `if`/`match`/block is
  marked by span and seeded from the declared `(P...) -> R` return type when it
  is lowered; a generic function's returned lambda is seeded the same way (type
  parameters resolve as the body resolves them).
- **#8605.** `lyric fmt` keeps a `wraps:`/`inside:` clause after `matches:` when
  the source wrote it there (`AspectDecl.orderOffset`); `@stubbable` now
  synthesises async methods (an `async` stub method returning its `_value`).
- **#8666.** `lyric test --coverage` braces a hit placed on a bare
  `case X -> return e` / `throw` arm so the rewritten source parses.
- **#8665 (D304).** A woven aspect contract whose generic call needs the
  unsigned/equality/operator re-check is M0009; the violation of a woven
  `ensures:` that calls a generic is tested; T0123 no longer says "make pub" for
  a name that is already pub.
