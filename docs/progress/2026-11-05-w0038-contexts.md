# W0038 learns the contexts that already fix a construction (docs/70 phase 3a, D380)

The checker's unsolved-construction rule (W0038, D353) now reads a `try`'s join
of body and handlers, tuple and list-literal elements, constructions in the
branches of a `?` operand, nested constructor fields, explicit type-argument
calls and lambda bodies. The 60 sites of the first census are gone locally; the
CI logs of this change are the next census. See D380.
